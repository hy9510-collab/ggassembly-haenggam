# 2026 행정사무감사 준비 (경기도의회 문화체육관광위원회)

문화체육관광국 7과·전국체전추진단과 산하기관 10곳의 행정사무감사 준비 자료를 한 페이지에서 보는 도구입니다.

## 여는 방법
- 바탕화면 바로가기 **「2026 행정사무감사 준비」** 를 두 번 누르거나
- `index.html` 파일을 두 번 누릅니다. (인터넷 연결 없이도 열립니다)

## 페이지 구성
| 탭 | 내용 |
| --- | --- |
| 📊 대시보드 | 오늘 새 기사, 쟁점 현황, 추천 의제 요약 |
| 🎯 행감 의제 | 여러 기관에 걸친 큰 주제와 진행 방법 |
| 🏢 기관·부서별 | 기관별 현황·예산·주요사업·이슈·질의·기사·자료 |
| 📝 질의·자료요구 | 기관별 질의와 자료요구, 공통 자료요구 |
| ⚖ 정부·타 시도 | 정부 방침·다른 시도 사례와 경기도 비교 |
| 🏛 분야 정책·보도자료 | 기관과 무관한 문화체육관광 분야 전반 |
| 🔥 쟁점 보도 | 2026년 쟁점 기사 전수 |
| 📰 언론보도 모아보기 | 수집한 기사 전체 검색 |
| 📋 2025 지적사항 | 지난해 지적과 처리 상태 |
| 📁 참고자료 | 2025 행감·업무보고 원본 파일 링크 |

## 매일 자동 갱신
Claude 예약 작업 `haenggam-news-daily` 가 매일 오전 7시에 기사·보도자료를 모아
쟁점·질의·자료요구·정부 비교·의제에 **추가**합니다(기존 내용은 지우지 않습니다).
컴퓨터가 켜져 있고 Claude 앱이 열려 있을 때 실행됩니다.

## 직접 실행할 때
| 파일 | 하는 일 |
| --- | --- |
| `뉴스수집.bat` | 기사·보도자료 다시 수집 (`data/news.json`, `data/news_data.js`) |
| `이슈반영.py` | `data/_issue_patch.json` 의 내용을 페이지에 반영 |
| `질의서_문서만들기.bat` | `문서/` 폴더에 질의서·자료요구목록 한글문서 생성 |
| `바탕화면 바로가기 만들기.bat` | 바탕화면 바로가기 다시 만들기 |

## 참고
`참고자료/` 폴더(2025 행감 요구자료·업무보고 원본, 약 5GB)는 용량이 커서 이 저장소에 올리지 않았습니다.
페이지의 📁 참고자료 탭은 내 컴퓨터의 해당 폴더를 가리킵니다.
